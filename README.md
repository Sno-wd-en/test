# Valentine's Day Website ❤️

A beautiful, romantic website to celebrate Valentine's Day 2026!

## Features

- 💖 Beautiful pink gradient background with animated floating hearts
- 💕 Heartbeat animations and smooth transitions
- 🌹 Three feature cards: Send Love Notes, Share Roses, and Sweet Treats
- 💌 Romantic love quotes from famous authors
- 📱 Fully responsive design that works on all devices
- ✨ Interactive hover effects and animations

## How to View the Website

### Option 1: Open Directly
Simply open `index.html` in your web browser by double-clicking the file.

### Option 2: Use Python HTTP Server
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

### Option 3: Use Node.js HTTP Server
```bash
npx http-server -p 8000
```
Then visit `http://localhost:8000` in your browser.
